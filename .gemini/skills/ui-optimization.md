# Skill: UI Optimization

## Limpeza de Botões Mortos
- Todo botão que não possui funcionalidade implementada deve ser removido ou documentado como "Simulation Only".
- Priorizar a remoção (purge) de elementos nativos do WhatsApp que não serão usados no BotArena.

## Performance
- Minimizar o uso de bibliotecas externas no frontend.
- Utilizar Vanilla CSS e JS.
